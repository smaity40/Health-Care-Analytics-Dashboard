# 🏥 Healthcare Analytics Dashboard

An interactive **Healthcare Analytics Dashboard built with Microsoft Power BI** to analyze healthcare data and generate meaningful, data-driven insights.

The project demonstrates an end-to-end **Data Analytics and Business Intelligence workflow**, including data preparation, transformation, KPI development, visualization, and dashboard design.

---

## 📊 Project Overview

Healthcare organizations generate large amounts of patient and operational data. Analyzing this data can help identify trends, understand patient demographics, monitor healthcare metrics, and support data-driven decision-making.

This project transforms healthcare data into an interactive Power BI dashboard that allows users to explore important healthcare metrics through KPIs, charts, filters, and analytical views.

### 🎯 Objectives

- Analyze healthcare and patient-related data
- Identify important trends and patterns
- Monitor key healthcare KPIs
- Analyze patient demographics
- Analyze medical conditions
- Compare different healthcare categories
- Build an interactive Power BI dashboard
- Generate meaningful business insights

---

## ❓ Business Questions

The dashboard helps answer questions such as:

- What is the total number of patients?
- What are the major patient demographic patterns?
- Which medical conditions occur most frequently?
- How are healthcare metrics changing over time?
- Which categories contribute most to the overall metrics?
- How do different patient segments compare?
- What patterns can be identified from the healthcare data?

## 📈 Dashboard Features

### 👥 Patient & Demographic Analysis

- Patient distribution
- Age analysis
- Gender analysis
- Demographic comparisons
- Patient segmentation

### 🏥 Medical Condition Analysis

- Medical condition distribution
- Patient count by condition
- Category comparisons
- Healthcare trends

### 📊 KPI Analysis

The dashboard provides important KPI cards and analytical metrics to give users a quick overview of healthcare performance.

### 🔎 Interactive Analysis

Users can interact with the dashboard using:

- Slicers
- Filters
- Charts
- KPI cards
- Interactive visualizations
